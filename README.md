# CV 2-40 - Система записи видео с веб-камеры

Проект для захвата и записи видео с веб-камеры с применением эффектов обработки изображения.

## 📋 О проекте

Проект представляет собой полнофункциональную систему для работы с веб-камерой, включающую захват видео в реальном времени, применение фильтров обработки изображения, запись видеофайлов и отображение служебной информации. Реализован на базе библиотеки OpenCV с поддержкой аппаратного ускорения.

**Особенности реализации:**
- Захват видео с веб-камеры в реальном времени
- Применение эффектов обработки изображения (черно-белый фильтр, размытие)
- Расчет и отображение FPS в реальном времени
- Управление записью видеофайлов с автоматическим именованием
- Корректное освобождение ресурсов при завершении работы

## 🎯 Функциональность

### Основные возможности
- **Захват видео**: Реализован через `cv2.VideoCapture(0)` с обработкой ошибок подключения
- **Эффекты обработки**: Конвертация в grayscale и Gaussian blur 
- **Управление записью**: Запуск/остановка записи по клавише 'z'
- **Интерфейс**: Отображение FPS и статуса записи поверх видео
- **Автономеняция**: Автоматическая генерация имен файлов (recording_001.avi, recording_002.avi)

### Управление клавишами
- **'z'** - Запуск/остановка записи
- **'q'** - Выход из приложения

## ⚙️ Архитектура класса

### Инициализация Video_Maker
```python
video = Video_Maker(output_dir="recordings", target_fps=20.0)
```

**Параметры:**
- `output_dir` (по умолчанию: "recordings") - Директория для сохранения записей
- `target_fps` (по умолчанию: 20.0) - Целевой FPS для выходного видео

### Основные методы

#### `fps_()`
Расчет FPS в реальном времени на основе временных меток кадров.

#### `effect()`
Применение эффектов обработки изображения:
- Конвертация в черно-белый формат
- Gaussian blur для сглаживания

#### `output()`
Добавление UI элементов:
- Отображение текущего FPS
- Индикатор статуса записи (REC/STOP)
- Вывод обработанного кадра в окно

#### `record_video()`
Управление процессом записи:
- Обработка нажатия клавиши 'z'
- Автоматическое создание уникальных имен файлов
- Инициализация и освобождение VideoWriter

#### `start_work()`
Главный цикл обработки:
- Захват кадров с камеры
- Обработка изображения
- Отображение интерфейса
- Управление записью

#### `clear_memory()`
Корректное освобождение ресурсов:
- Закрытие файлов записи
- Освобождение камеры
- Закрытие окон OpenCV

## 💡 Пример использования

```python
# Создание экземпляра с кастомными параметрами
video_recorder = Video_Maker(
    output_dir="my_recordings",  
    target_fps=30.0              
)

# Запуск системы
video_recorder.start_work()
```
